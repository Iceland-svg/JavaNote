配置详解：

```
id : ⾃定义路由ID, 保持唯⼀

uri : ⽬标服务地址, ⽀持普通URI 及 lb://应⽤注册服务名称 . lb表⽰负载均衡, 使⽤ lb://
⽅式表⽰从注册中⼼获取服务地址

predicates : 路由条件, 根据匹配结果决定是否执⾏该请求路由, 上述代码中, 我们把符合Path规
则的⼀切请求, 都代理到uri参数指定的地址

filters ：于定义在请求转发到⽬标地址之前或之后执⾏的过滤器

StripPrefix ：这是⼀个StripPrefix过滤器，它的作⽤是从请求的路径中去除⼀部分前
缀 StripPrefix=1 表⽰去除1个路径段。例如，如果原始请求的路径是
/mstemplate/test ，那么经过这个过滤器处理后，转发到⽬标服务的路径就变成了/test 
```
