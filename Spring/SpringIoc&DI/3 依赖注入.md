
依赖注入分为属性注入，构造方法注入，Setter注入

### 1 属性注入

最简单的直接加上@Autowired  

```java
@Component  
public class BookService {  
    @Autowired  
    private BookDao bookDao;  
  
    public List<BookInfo> getList(){  
        // BookDao  bookDao = new BookDao();  
        List<BookInfo> bookInfos = bookDao.mockBookDate();  
        for(BookInfo bookInfo : bookInfos){  
            if(bookInfo.getStatus() == 1){  
            bookInfo.setStatusCN("可借阅");  
            }else {  
            bookInfo.setStatusCN("不可借阅");  
        }  
    }  
    return bookInfos;  
}
```

### 2 构造方法注入


```java
@Controller  
public class UserController {  
    private UserService userService;  
    public UserController(UserService userService) {  
        this.userService = userService;  
    }  
  
    public void hello(){  
        System.out.println("hello");  
    }
```

如果存在多个构造方法Spring会优先使用无参的构造方法，想要指定可以加上@Autowired注解来指定

```java
@Controller  
public class UserController {  
    private UserService userService;  
    @Autowired  
    public UserController(UserService userService) {  
        this.userService = userService;  
    }  
  
    public UserController() {  
    }  
  
    public void hello(){  
        System.out.println("hello");  
    }  
}
```

同理多个有参也可以通过@Autowired来指定

```java
@Controller  
public class UserController {  
    private UserService userService;  
    private UserConfig userConfig;  
    @Autowired  
    public UserController(UserService userService) {  
        this.userService = userService;  
    }  
    public UserController(UserService userService, UserConfig userConfig) {  
        this.userConfig = userConfig;  
        this.userService = userService;  
    }  
    //    public UserController() {  
//    }  
  
    public void hello(){  
        System.out.println("hello");  
    }  
}
```

### @Autowired存在的一些问题

假如我们给UserController注入UserInfo类的对象，此时有userInfo1和userInfo2
Spring会不知道到底注入那一个

```java
@Autowired  
private UserInfo userInfo;
```

### 方法一

通过@Primary来选择想要注入的bean

```java
@Component("userConponent2")  
public class UserConponent {  
   public void hello(){  
       System.out.println("hello");  
   }  
   @Primary  
   @Bean   
   public UserInfo userInfo(){  
       return new UserInfo("zs",20);  
   }  
   @Bean  
    public UserInfo userInfo2(){  
        return new UserInfo("ls",19);  
    }  
}
```

方法二

直接指定想要注入的依赖

```java
@Qualifier("userInfo1")
@Autowired 
private UserInfo userInfo;
```

方法三

利用JDK提供的@Resource注解

```java
@Resource(name = "userInfo1")
private UserInfo userInfo;
```

## 5 @Resource和@Autowired的区别

（1）一个是JDK提供的注解，一个是Spring框架提供的注解
（2）@Autowired默认是按照类型注入的（找到多个对象则会考虑名称），@Resource是按照名称注入的（内部先找到这个类型再根据名称去找），@Resuorce,多了一个参数设置
## 6 Spring,SpringBoot,Spring MVC的关系及区别
#### （1）Spring
Spring是一个应用开发框架，有轻量化，一站式，模块化的特点，主要用来管理对象，以及对象之间的依赖关系, 数据库事务管理，数据访问，Web 框架支持，具有高开放性的特点，像是Spring AI 自己不选择开发，选择接入其他AI
#### （2）Spring MVC 
Spring MVC是 Spring的一个子框架，用来开发Web应用和网络接口，那些@RequestMapping这样的接口就属于Spring MVC
####   (3)Spring Boot
Spring Boot 是对Spring的封装，他出现的意义就是为了简化Spring应用的开发
