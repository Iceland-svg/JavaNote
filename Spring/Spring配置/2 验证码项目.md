### 3 利用配置文件的写法
把常用量写入配置文件（写死验证码长宽）直接通过@ConfigurationProperties来获取

```XML
captcha:  
  width: 160  
  heigth: 60
```

```java
@Data  
@Configuration  
@ConfigurationProperties(prefix = "captcha")  
public class CaptchaProperties {  
    private Integer width;  
    private Integer heigth;  
}
```

接着我们就可以直接注入captchaProperties对象，通过get方法获取长宽


```java
RestController  
@RequestMapping("/captcha")  
public class CaptchaController {  
    @Autowired  
    private CaptchaProperties captchaProperties;  
    @RequestMapping("/getCaptcha")  
    public void getCaptcha(HttpServletResponse response){  
        LineCaptcha lineCaptcha = CaptchaUtil.createLineCaptcha(captchaProperties.getWidth(),captchaProperties.getHeigth());  
        Console.log(lineCaptcha.getCode());  
        try {  
            lineCaptcha.write(response.getOutputStream());  
        } catch (IOException e) {  
            throw new RuntimeException(e);  
        }  
    }
```

此处的配置文件处理一方面便于直接用最适合的大小了，另一方面便于后期的维护修改

校验验证码逻辑

除了基本的从session中获取验证码外需要设置时间，限制验证码的失效性

```java
@RestController  
@RequestMapping("/captcha")  
public class CaptchaController {  
    @Autowired  
    private CaptchaProperties captchaProperties;  
    private static Long VILID_MILLIS_TIME = 300000L;  
    @RequestMapping("/getCaptcha")  
    public void getCaptcha(HttpServletResponse response, HttpServletRequest request){  
        HttpSession session = request.getSession();  
        LineCaptcha lineCaptcha = CaptchaUtil.createLineCaptcha(captchaProperties.getWidth()  
                ,captchaProperties.getHeigth());  
        String code = lineCaptcha.getCode();  
        try {  
                //告诉浏览器返回的数据格式，方便浏览器解析  
                response.setContentType("image/jpeg");  
                //告诉浏览器不要缓存这个响应，防止使用缓存的旧图片，保证每次显示的都是新的  
                response.setHeader("Pragma","No-cache");  
                //把验证码写入到Session中（同时存在多个用户时/多线程模式/时不能用单个验证码对象，这个对象会被反复修改，校验会失效）  
            session.setAttribute("code",code);  
            session.setAttribute("time",System.currentTimeMillis());  
            lineCaptcha.write(response.getOutputStream());  
            response.getOutputStream().close();  
        } catch (IOException e) {  
            throw new RuntimeException(e);  
        }  
    }  
    @RequestMapping("/check")  
    public Boolean checkCaptcha(HttpSession session,String captcha){  
        //从Session中获取验证码  
        if(!StringUtils.hasLength(captcha)){  
            return false;  
        }  
        String code = (String) session.getAttribute("code");  
        Long time = (Long)session.getAttribute("time");  
        Long curTime = System.currentTimeMillis();  
        if(captcha.equalsIgnoreCase(code) && curTime-time < VILID_MILLIS_TIME) {  
            return true;  
        }  
        return false;  
    }  
}
```
