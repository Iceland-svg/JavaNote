添加ControllerAdvice和@ResponseBody注解
写handler方法
```java
@Slf4j  
@ControllerAdvice  
@ResponseBody  
//将控制器返回值写入响应体，自动转化为指定的格式  
public class ExceptionAdvice {  
  
    @ExceptionHandler  
    public Result handler(Exception e){  
        log.error("发生异常 e:"+e);  
        return Result.fail(-1,e.getMessage());  
    }  
    @ExceptionHandler  
    public Result handler(ArithmeticException e){  
        log.error("发生算数异常e:"+e);  
        return Result.fail(-3,e.getMessage());  
    }  
    @ExceptionHandler  
    public Result handler(NullPointerException e){  
        log.error("发生异常 e:"+e);  
        return Result.fail(-2,"发生空指针异常");  
    }  
    //也可以在这注解里写
    @ExceptionHandler(IndexOutOfBoundsException.class)  
    public Result handler2(){  
        log.error("发生异常");  
        return Result.fail(-4,"数组越界异常");  
    }  
}
```
