```java
@RestController  
@RequestMapping("/user")  
public class UserController {  
    @Autowired  
    private UserService userService;  
    //开启事务  
    @Autowired  
    private DataSourceTransactionManager dataSourceTransactionManager;  
    @Autowired  
    private TransactionDefinition transactionDefinition;  
  
    @RequestMapping("/registry")  
    public String registryUser(UserInfo userInfo){  
        //开启事务  
        TransactionStatus transaction = dataSourceTransactionManager.getTransaction(transactionDefinition);  
        //用户注册  
        userService.insertUser(userInfo);  
        //回滚事务/提交事务  
        dataSourceTransactionManager.rollback(transaction);  
        //dataSourceTransactionManager.commit(transaction);  
        return "";  
    }  
    //事务提交
    @Transactional  
    @RequestMapping("/t1")  
    public String t1(UserInfo userInfo) {  
        userService.insertUser(userInfo);  
        return "";  
    }
    //发生异常时提交回回滚
    @Transactional  
    @RequestMapping("/t2")  
    public String t2(UserInfo userInfo){  
        Integer result = userService.insertUser(userInfo);  
        int a = 10/0;  
        return  "";  
    }  
    @Transactional  
    @RequestMapping("/t3")  
    public String t3(UserInfo userInfo){  
        Integer result = userService.insertUser(userInfo);  
    try {  
        int a = 10/0;  
        } catch (Exception e) {  
        throw new RuntimeException(e);  
    }  
        return  "";  
    }
}
```
@Transactional注解，修饰方法时只有public才能生效
修饰类时对类中所有public方法生效
被@Transactional注解修饰后自动开启事务，执行完后自动提交，但是也分以下几种情况：

（1）提交未发生异常：事务提交
（2）提交时发生异常未捕获：事务回滚（不是所有异常都会回滚，只有Error,RuntimeException才会回滚）

当碰到不会回滚的异常时可以设置rollBackFor


```java
//加上大括号，指定多个异常
@Transactional(rollbackFor = {Exception.class})  
@RequestMapping("/t5")  
public String t5(UserInfo userInfo) throws IOException {  
    Integer result = userService.insertUser(userInfo);  
    if(true){  
        throw new IOException();  
    }  
    return  "用户注册成功";  
}
```

（3）提交时发生异常被捕获：事务提交成功

发生异常时被捕获，希望回滚，可以手动设置

```Java
@Transactional  
@RequestMapping("/t4")  
public String t4(UserInfo userInfo){  
    Integer result = userService.insertUser(userInfo);  
    try {  
        int a = 10/0;  
    } catch (Exception e) {  
        log.info("程序发生异常，被捕获");  
        TransactionAspectSupport.currentTransactionStatus().setRollbackOnly();  
    }  
    return  "";  
}
```
