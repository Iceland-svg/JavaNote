## 1 网络通信api

主要是传输层提供的api，传输层提供的网络通信api也称为Socket api（网络编程套接字）
传输层主要涉及到TCP和UDP协议，这两个协议分别提供了两组Soket api

### TCP和UDP特点

TCP：有连接（通信时保存对方的信息），可靠传输（TCP尽可能保证数据能被对应端收到），面向字节流（读写数据的基本单位是字节），全双工（一个信道双向通信）

UDP：无连接（通信时不保存对方信息），不可靠传输（UDP把数据包发出后就不管了），面向数据报（读取数据基本单位是数据报），全双工（一个信道双向通信）网络通信程序基本流程

### 如何理解DategramSocket?

这个类代表了操作系统中的Socket文件

### 如何理解网卡？

网卡是通过文件来进行封装的，通过网络发送数据就是往网卡中写入数据
接受数据就是从网卡中读取数据，此处封装网卡的文件就是Socket文件，所以本质上通过这个类创建Socket对象就是打开一个Socket文件

### 什么是DategramPacket？

传输的时的基本单位，实际上是包装了一个字节数组
客户端（发起通信）
服务端（接受通信）

首先创建socket对象，然后绑定端口号
一个端口同一时刻只能被同一个进程或者socket绑定

服务端代码

```java
public class EchoServer {  
    //创建Socket对象  
    private DatagramSocket socket;  
    //构造实例，带有端口号(绑定端口号)  
    public EchoServer(int port) throws IOException {  
        socket = new DatagramSocket(port);  
    }  
    //启动服务器并实现业务逻辑的方法  
    public void start() throws IOException{  
        while (true) {  
            //读取请求并解析  
            //创建一个空白的Datagram对象，指定字节数组，用来放数据报内容  
            DatagramPacket reqPacket = new DatagramPacket(new byte[4096],4096);  
            //这里是返回型参数，把接收到的数据放入reqPacket，如果没有接收到数据就会阻塞  
            socket.receive(reqPacket);  
            //从二进制转化为字符串,获取数据，截取有效长度  
            String request =new String(reqPacket.getData(), 0, reqPacket.getLength());  
            //根据请求计算响应  
            String response = process(request);  
            //把响应写回客户端,从字符串解析回字节数组  
            //拿到reqPacket数据报里的信息，作为respPacket的返回信息  
            DatagramPacket respPacket = new DatagramPacket(response.getBytes(),  
                    response.getBytes().length,reqPacket.getSocketAddress());  
            //谁发的请求就返回给谁  
            socket.send(respPacket);  
            //日志查看  
            System.out.printf("[%s:%d] req: %s, resp: %s\n"  
                    ,reqPacket.getAddress(), reqPacket.getPort(), request, response);  
        }  
    }  
    public String process(String request){  
        return request;  
    }  
    public static void main(String[] args) throws IOException {  
        EchoServer server = new EchoServer(9090);  
        server.start();  
    }  
}
```

客户端代码

```java
public class EchoClient {  
    //创建socket对象  
    private DatagramSocket socket;  
    //需要有服务器端口号和ip地址  
    private String serverIp;  
    private int serverPort;  
  
    public EchoClient(String serverIp, int serverPort) throws SocketException {  
        this.serverIp = serverIp;  
        this.serverPort = serverPort;  
        socket = new DatagramSocket();  
    }  
    public void start() throws IOException{  
        Scanner scanner = new Scanner(System.in);  
        System.out.println("客户端启动");  
        while (true) {  
            //从控制台读取用户输入内容  
            System.out.println("> ");  
            String request = scanner.next();  
            //构造成UDP请求并发送  
            DatagramPacket reqPacket = new DatagramPacket(request.getBytes(),  
                    0 ,request.getBytes().length, InetAddress.getByName(serverIp), serverPort);  
            socket.send(reqPacket);  
            //读服务器响应  
            DatagramPacket respPacket = new DatagramPacket(new byte[4096],4096);  
            socket.receive(respPacket);  
            //把响应显示到控制台  
            String response = new String(respPacket.getData()  
                    , 0, respPacket.getLength());  
            System.out.println(response);  
        }  
    }  
  
    public static void main(String[] args) throws IOException{  
        EchoClient echoClient = new EchoClient("127.0.0.1",9090);  
        echoClient.start();  
    }  
}
```

```java
public class EchoServer {  
    //ServerSocket的主要作用是监听端口，接受连接  
    private ServerSocket serverSocket;  
    public EchoServer(int port) throws IOException{  
        //我们这里自己设置端口，服务器启动就会绑定到端口上  
        serverSocket = new ServerSocket(port);  
    }  
    public void start() throws IOException {  
        System.out.println("服务器启动");  
        while (true){  
            //操作系统内核已经连接好了服务端和客户端，我们只需要调用accept接电话就可以了  
            Socket socket = serverSocket.accept();  
            processConnection(socket);  
        }  
    }  
    //处理连接的方法  
    public void processConnection(Socket socket)throws IOException{  
        System.out.printf("[%s:%d] 客户端上线！\n",socket.getInetAddress().toString(),  
        socket.getPort());  
        //把字节输入流，字节输出流写入括号里，保证自动关闭  
        try (InputStream inputStream = socket.getInputStream();  
        OutputStream outputStream = socket.getOutputStream();){  
            //读取客户端数据，这里其实是用字符流包装（将字节流转化为字符流）  
            Scanner scanner = new Scanner(inputStream);  
            //向客户端发送数据  
            PrintWriter writer = new PrintWriter(outputStream);  
            while (true){  
                //客户端下线逻辑的处理  
                if(scanner.hasNext()){  
                    System.out.printf("[%s:%d] 客户端下线\n",socket.getInetAddress().toString()  
                    ,socket.getPort());  
                    break;  
                }  
                String request = scanner.next();  
                //根据请求计算响应  
                String response = process(request);  
                //把响应写回客户端  
                writer.println(response);  
            }  
        }catch (Exception e){  
            e.printStackTrace();  
        }  
  
    }  
    //处理请求的方法  
    private String process(String request){  
        return request;  
    }  
  
    public static void main(String[] args) {  
  
    }  
}
```
