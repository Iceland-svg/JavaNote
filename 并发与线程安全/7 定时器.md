## 4 自实现定时器

```java
import java.util.PriorityQueue;  
  
class MyTimerTask implements Comparable<MyTimerTask>{  
    private Runnable task;  
    private long time;  
  
    public MyTimerTask(Runnable task, long delay) {  
        this.task = task;  
        //转化为时间戳  
        this.time = System.currentTimeMillis() + delay;  
    }  
  
    public long getTime() {  
        return time;  
    }  
  
    public Runnable getTask() {  
        return task;  
    }  
  
    @Override  
    public int compareTo(MyTimerTask o) {  
        return (int) (this.time-o.time);  
    }  
}  
public class myTimer {  
    private Object locker;  
    private PriorityQueue<MyTimerTask> queue = new PriorityQueue<>();  
    public myTimer(){  
       Thread thread = new Thread(()->{  
          while(true){  
              try {  
                  synchronized (locker){  
                          if(queue.isEmpty()) {  
                              locker.wait();  
                          }  
                          MyTimerTask task = queue.peek();  
                          long curTime = System.currentTimeMillis();  
                          if(curTime < task.getTime()){  
                              //没有新任务就一直等  
                              //随时有新任务就要随时唤醒  
                              //前一个wait被短暂唤醒到这里又会阻塞  
                              locker.wait(task.getTime()-curTime);  
                          }else {  
                              task.getTask().run();  
                              queue.poll();  
                          }  
                  }  
              } catch (InterruptedException e) {  
                  e.printStackTrace();  
              }  
          }  
       });  
       thread.start();  
    }  
    //schedule的作用就是把任务和等待执行任务的时间传给MyTimerTask再放进优先队列里  
    public void schedule(Runnable runnable, long delay){  
        synchronized (locker){  
            queue.offer(new MyTimerTask(runnable, delay));  
            locker.notify();  
        }  
    }  
  
}
```

第二个wait什么用?
假设在14：00开始，有一个14：30的任务就会设置30分钟的等待时间，时间到了就执行
如果在30分钟内有14：15的新任务来了，就会把这个wait唤醒，去重新设置新任务时间
如果在三十分钟内有15：00的任务来了，虽然wait被唤醒了，但是还是会优先根据未完成的14：30的任务设置时间
