借助工具hutool实现

### 1 添加依赖以此使用该工具

```XML
<dependency>  
    <groupId>cn.hutool</groupId>  
    <artifactId>hutool-captcha</artifactId>  
    <version>5.8.22</version>  
</dependency>
```

### 2 从官方网站上获取并简单测试功能

```java
public class CaptchaTest {  
    public static void main(String[] args) {  
        //定义验证码长度和宽  
        LineCaptcha lineCaptcha = CaptchaUtil.createLineCaptcha(150,60);  
        //图形验证码写出  
        lineCaptcha.write("d:/验证码/line.png");  
        //输出Code  
        Console.log(lineCaptcha.getCode());  
        Boolean verify = lineCaptcha.verify("1234");  
        System.out.println("验证结果："+verify);  
    }  
}
```

### 3 表示层接口实现

```java
@RestController  
@RequestMapping("/captcha")  
public class CaptchaController {  
    @RequestMapping("/getCaptch")  
    public void getCaptcha(HttpServletResponse response){  
        LineCaptcha lineCaptcha = CaptchaUtil.createLineCaptcha(150,60);  
        Console.log(lineCaptcha.getCode());  
        try {  
        //这里的验证码对象是图片所以要将验证码写入输出字节流
            lineCaptcha.write(response.getOutputStream());  
        } catch (IOException e) {  
            throw new RuntimeException(e);  
        }  
    }  
}
```

### 3 利用配置文件的写法
把常用量写入配置文件（写死验证码长宽）直接通过@ConfigurationProperties来获取

```XML
captcha:  
  width: 160  
  heigth: 60
```

```java
@Data  
@Configuration  
@ConfigurationProperties(prefix = "captcha")  
public class CaptchaProperties {  
    private Integer width;  
    private Integer heigth;  
}
```

接着我们就可以直接注入captchaProperties对象，通过get方法获取长宽


```java
RestController  
@RequestMapping("/captcha")  
public class CaptchaController {  
    @Autowired  
    private CaptchaProperties captchaProperties;  
    @RequestMapping("/getCaptcha")  
    public void getCaptcha(HttpServletResponse response){  
        LineCaptcha lineCaptcha = CaptchaUtil.createLineCaptcha(captchaProperties.getWidth(),captchaProperties.getHeigth());  
        Console.log(lineCaptcha.getCode());  
        try {  
            lineCaptcha.write(response.getOutputStream());  
        } catch (IOException e) {  
            throw new RuntimeException(e);  
        }  
    }
```

此处的配置文件处理一方面便于直接用最适合的大小了，另一方面便于后期的维护修改
