简单来说适配器就是通过一个工具可以获取插座不同电压的电，这个电是本来获取不到的，通过适配器转化就可以获取得到，程序里，适配器模式让我们通过一个接口可以统一获取不同的，功能相似的类，的方法，

代码举例

```java
  
public class Log4jApi {  
    public void log(String message){  
        System.out.println("log4j打印日志 "+message);  
    }  
}
```



```java
  
public class LogBackApi {  
    public void print(String message){  
        System.out.println("LogBack打印日志"+message);  
    }  
}
```



```java
public class Log4jAdapter implements Slf4jApi{  
  
    private Log4jApi log4jApi;  
  
    public Log4jAdapter(Log4jApi log4jApi) {  
        this.log4jApi = log4jApi;  
    }  
  
    @Override  
    public void logger(String message) {  
        log4jApi.log(message);  
    }  
}
```



```java
public class LogBackAdapter implements Slf4jApi{  
    private LogBackApi logBackApi;  
  
    public LogBackAdapter(LogBackApi logBackApi) {  
        this.logBackApi = logBackApi;  
    }  
  
    @Override  
    public void logger(String message) {  
        logBackApi.print(message);  
    }  
}
```



```java
public interface Slf4jApi {  
    public void logger(String message);  
}
```



```java
public class Main {  
    public static void main(String[] args) {  
        Slf4jApi slf4jApi = new Log4jAdapter(new Log4jApi());  
        slf4jApi.logger("打印日志");  
    }  
}
```
