Java的数据类型主要分为两大类：**基本数据类型**（Primitive Types）和**引用数据类型**（Reference Types）。

---

### 一、基本数据类型

基本数据类型是Java语言内置的、不可简化的类型，它们直接存储值，通常存储在**栈内存**中。一共有8种，可以分为四大类：

| 类型 | 关键字 | 占用字节 | 默认值 | 取值范围/说明 |
| :--- | :--- | :--- | :--- | :--- |
| **整型** | `byte` | 1 | 0 | -128 ~ 127 |
| | `short` | 2 | 0 | -2^15 ~ 2^15-1 |
| | **`int`** | 4 | 0 | -2^31 ~ 2^31-1 **(最常用)** |
| | `long` | 8 | 0L | -2^63 ~ 2^63-1，赋值时需加后缀 **L** (如 `100L`) |
| **浮点型** | `float` | 4 | 0.0f | 单精度，赋值时需加后缀 **F** (如 `3.14f`) |
| | **`double`** | 8 | 0.0d | 双精度，**默认的小数类型** (如 `3.14`) |
| **字符型** | `char` | 2 | '\u0000' | 单个字符，用单引号表示，采用Unicode编码 (0~65535) |
| **布尔型** | `boolean` | 不精确(通常1字节) | false | 只有 `true` 和 `false` |

---

### 二、引用数据类型

引用数据类型存储的是**对象的地址引用**（指针），而不是数据本身。对象通常存储在**堆内存**中。

1.  **类 (Class)**：包括 `String` 以及所有自定义的类。
2.  **接口 (Interface)**：如 `List`、`Map`。
3.  **数组 (Array)**：如 `int[]`、`String[]`。

**特别注意 `String`**：虽然它是一个类（引用类型），但因其使用频率极高且具备不可变性（immutable），Java对其做了特殊优化（字符串常量池）。

---

### 三、关键区别与面试要点

#### 1. 存储位置
-   **基本类型**：值直接保存在**栈**中，存取效率高。
-   **引用类型**：栈中保存的是**堆内存的地址**，实际对象保存在堆中。

#### 2. 默认值
-   **局部变量**（方法内）：基本数据类型没有默认值，必须显式初始化后才能使用。
-   **成员变量**（类中）：基本数据类型有默认值（如上表），引用类型默认值为 `null`。

#### 3. 包装类
为了能让基本数据类型支持面向对象的操作（如用于集合 `ArrayList` 中），Java为每个基本类型提供了对应的包装类（Wrapper Class）：

-   `int` -> **`Integer`**
-   `double` -> **`Double`**
-   `char` -> **`Character`**
-   `boolean` -> **`Boolean`**

**自动装箱与拆箱**：Java支持自动转换。
```java
Integer i = 100; // 自动装箱 (int -> Integer)
int n = i;       // 自动拆箱 (Integer -> int)
```

#### 4. 缓存池
`Integer`、`Byte`、`Short`、`Long`、`Character` 这几种包装类在内部实现了**缓存池**。
-   例如 `Integer` 默认缓存了 `-128` 到 `127` 之间的数值。
-   在这个范围内，`Integer a = 100; Integer b = 100;`，`a == b` 为 `true`；超出范围则为 `false`。

---

### 四、总结对比

| 特性 | 基本数据类型 | 引用数据类型 |
| :--- | :--- | :--- |
| **存储** | 栈 | 堆（地址在栈） |
| **值** | 具体数值 | 内存地址（或 null） |
| **创建方式** | `int a = 5;` | `new` 关键字（String字面量除外） |
| **生命周期** | 随方法调用结束而销毁 | 由GC（垃圾回收器）管理 |
